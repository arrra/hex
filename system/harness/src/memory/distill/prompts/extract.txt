single slice of an assistant-session transcript. The goal is memory that stays
true and useful days or weeks later — identity, stable preferences, firm
decisions, project state and ownership — not passing chatter.

Return ONLY a JSON array. Each element is an object with exactly these four
keys:

  {"subject": "...", "predicate": "...", "object": "...", "importance": 0.0}

- predicate MUST be one of this exact vocabulary — pick the closest fit and use
  it verbatim, never invent a new predicate:
  [[PREDICATES]]
- subject: a stable, canonical name for who or what the fact is about. Use
  proper names or durable identifiers, never pronouns like "he", "she", "they",
  or "the user". Refer to the same entity by the same name every time.
- object: a self-contained value that reads correctly on its own, without the
  surrounding transcript. Spell out what a reference points to; do not rely on
  nearby lines for meaning.
- importance: a float from 0.0 to 1.0 measuring how durable and consequential
  the fact is:
    0.9+  durable identity, long-standing preferences, firm decisions
    ~0.5  concrete project facts, current focus, responsibilities
    <0.3  ephemera and one-off details unlikely to matter later
- Extract only what will plausibly still be true and worth recalling later.
  Skip small talk, transient status chatter, and anything you are unsure about.
- When nothing durable is present, return an empty array: []
- Output JSON only. No prose, no commentary, and no keys other than the four
  above. A single fenced ```json block or a bare array are both accepted.
